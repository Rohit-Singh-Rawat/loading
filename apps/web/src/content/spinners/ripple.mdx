import { Ripple } from "loading-dev";

## Props

### size

Sets the spinner's dimensions in pixels — the cells and the gaps between them
scale proportionally. Defaults to 20.

<DemoWithCode code={`<Ripple size={16} />
<Ripple size={24} />
<Ripple size={40} />`}>
  <div className="flex items-center gap-6">
    <Ripple size={16} />
    <Ripple size={24} />
    <Ripple size={40} />
  </div>
</DemoWithCode>

### className

Merged onto the root element, so utilities land on the spinner itself.

<DemoWithCode code={`<Ripple className="opacity-40" size={32} />`}>
  <Ripple className="opacity-40" size={32} />
</DemoWithCode>

## Styling

### color

The cells inherit `currentColor`, so the CSS `color` property tints them.

<DemoWithCode code={`<div style={{ color: "#f97316" }}>
  <Ripple size={32} />
</div>`}>
  <div style={{ color: "#f97316" }}>
    <Ripple size={32} />
  </div>
</DemoWithCode>

### --ld-duration

Sets the time for one full pulse. Set it on any wrapper — it cascades down to
the spinner.

<DemoWithCode code={`<div style={{ "--ld-duration": "2.4s" }}>
  <Ripple size={32} />
</div>`}>
  <div style={{ "--ld-duration": "2.4s" }}>
    <Ripple size={32} />
  </div>
</DemoWithCode>

### --ld-play-state

Pauses or resumes the animation.

<DemoWithCode code={`<div style={{ "--ld-play-state": "paused" }}>
  <Ripple size={32} />
</div>`}>
  <div style={{ "--ld-play-state": "paused" }}>
    <Ripple size={32} />
  </div>
</DemoWithCode>

## Usage

The pulse starts at the center and pushes outward, then rests for a beat
before repeating. The pause makes it calmer than a continuous spinner, so it
works for background work the user is not waiting on. Set the variables on
any wrapper — they cascade down to the spinner.

```tsx title="background-task.tsx"
<div className="flex items-center gap-2 text-gray-500">
  <Ripple size={16} />
  Listening for changes…
</div>
```
