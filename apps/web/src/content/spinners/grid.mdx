import { Grid } from "loading-dev";

## Props

### size

Sets the spinner's dimensions in pixels — the cells and the gaps between them
scale proportionally, so the grid stays square at any size. Defaults to 20.

<DemoWithCode code={`<Grid size={16} />
<Grid size={24} />
<Grid size={40} />`}>
  <div className="flex items-center gap-6">
    <Grid size={16} />
    <Grid size={24} />
    <Grid size={40} />
  </div>
</DemoWithCode>

### className

Merged onto the root element, so utilities land on the spinner itself.

<DemoWithCode code={`<Grid className="opacity-40" size={32} />`}>
  <Grid className="opacity-40" size={32} />
</DemoWithCode>

## Styling

### color

The cells inherit `currentColor`, so the CSS `color` property tints them.

<DemoWithCode code={`<div style={{ color: "#f97316" }}>
  <Grid size={32} />
</div>`}>
  <div style={{ color: "#f97316" }}>
    <Grid size={32} />
  </div>
</DemoWithCode>

### --ld-duration

Sets the time for one full pass down the grid. Set it on any wrapper — it
cascades down to the spinner.

<DemoWithCode code={`<div style={{ "--ld-duration": "2.4s" }}>
  <Grid size={32} />
</div>`}>
  <div style={{ "--ld-duration": "2.4s" }}>
    <Grid size={32} />
  </div>
</DemoWithCode>

### --ld-play-state

Pauses or resumes the animation.

<DemoWithCode code={`<div style={{ "--ld-play-state": "paused" }}>
  <Grid size={32} />
</div>`}>
  <div style={{ "--ld-play-state": "paused" }}>
    <Grid size={32} />
  </div>
</DemoWithCode>

## Usage

A brightness wave falls one row at a time, which reads as steady progress
rather than an indefinite spin. It suits terminals, status bars, and any
surface with a pixel-leaning aesthetic. Set the variables on any wrapper —
they cascade down to the spinner.

```tsx title="status-bar.tsx"
<div className="flex items-center gap-2 text-gray-500">
  <Grid size={16} />
  Indexing…
</div>
```
