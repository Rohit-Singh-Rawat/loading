import { Ring } from "loading-dev";

## Props

### size

Sets the spinner's dimensions in pixels. Defaults to 20.

<DemoWithCode code={`<Ring size={16} />
<Ring size={24} />
<Ring size={40} />`}>
  <div className="flex items-center gap-6">
    <Ring size={16} />
    <Ring size={24} />
    <Ring size={40} />
  </div>
</DemoWithCode>

### className

Merged onto the root element, so utilities land on the spinner itself.

<DemoWithCode code={`<Ring className="opacity-40" size={32} />`}>
  <Ring className="opacity-40" size={32} />
</DemoWithCode>

## Styling

### color

Both the arc and the faint track inherit `currentColor`, so the CSS `color`
property tints them together.

<DemoWithCode code={`<div style={{ color: "#f97316" }}>
  <Ring size={32} />
</div>`}>
  <div style={{ color: "#f97316" }}>
    <Ring size={32} />
  </div>
</DemoWithCode>

### --ld-duration

Sets the rotation speed. Set it on any wrapper — it cascades down to the
spinner.

<DemoWithCode code={`<div style={{ "--ld-duration": "2s" }}>
  <Ring size={32} />
</div>`}>
  <div style={{ "--ld-duration": "2s" }}>
    <Ring size={32} />
  </div>
</DemoWithCode>

### --ld-play-state

Pauses or resumes the animation.

<DemoWithCode code={`<div style={{ "--ld-play-state": "paused" }}>
  <Ring size={32} />
</div>`}>
  <div style={{ "--ld-play-state": "paused" }}>
    <Ring size={32} />
  </div>
</DemoWithCode>

## Usage

The static track keeps the spinner's footprint visible at all times, which
makes it a good fit for progress affordances inside cards and panels where
layout stability matters. Set the variables on any wrapper — they cascade
down to the spinner.

```tsx title="card.tsx"
<div className="flex items-center gap-2 text-gray-500">
  <Ring size={16} />
  Syncing…
</div>
```
