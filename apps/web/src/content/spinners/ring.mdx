## Props

### size

Sets the spinner's dimensions in pixels. Defaults to 20.

<Demo name="ring/size" />

### className

Merged onto the root element, so utilities land on the spinner itself.

<Demo name="ring/class-name" />

## Styling

### color

Both the arc and the faint track inherit `currentColor`, so the CSS `color`
property tints them together.

<Demo name="ring/color" />

### --ld-duration

Sets the rotation speed. Set it on any wrapper — it cascades down to the
spinner.

<Demo name="ring/duration" />

### --ld-play-state

Pauses or resumes the animation.

<Demo name="ring/play-state" />

## Usage

The static track keeps the spinner's footprint visible at all times, which
makes it a good fit for progress affordances inside cards and panels where
layout stability matters. Set the variables on any wrapper — they cascade
down to the spinner.

```tsx title="card.tsx"
<div className="flex items-center gap-2 text-gray-500">
  <Ring size={16} />
  Syncing…
</div>
```
