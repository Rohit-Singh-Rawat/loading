## Changing Size

Sets the spinner's dimensions in pixels — the dots and their gap scale
proportionally. Defaults to 20.

## Changing Color

Tints the dots with any CSS color. Omit it and they inherit `currentColor`
from the surrounding text.

<Demo name="bouncing-dots/color" />

## Changing Duration

Sets the bounce speed in milliseconds; the stagger between dots stays
proportional at any speed. Set `--ld-duration` on a wrapper instead — it
cascades down to every spinner underneath.

<Demo name="bouncing-dots/duration" />

Pauses or resumes the animation.

<Demo name="bouncing-dots/play-state" />

## Usage

Bouncing dots read as "working on it" rather than "loading a page", which
makes them a good fit for chat interfaces and streaming responses. Set the
variables on any wrapper — they cascade down to the spinner.

```tsx title="typing-indicator.tsx"
<div className="text-gray-500">
  <BouncingDots size={16} />
</div>
```
