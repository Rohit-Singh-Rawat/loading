import { BouncingDots } from "loading-dev";

## Props

### size

Sets the spinner's dimensions in pixels — the dots and their gap scale
proportionally. Defaults to 20.

<DemoWithCode code={`<BouncingDots size={16} />
<BouncingDots size={24} />
<BouncingDots size={40} />`}>
  <div className="flex items-center gap-6">
    <BouncingDots size={16} />
    <BouncingDots size={24} />
    <BouncingDots size={40} />
  </div>
</DemoWithCode>

### className

Merged onto the root element, so utilities land on the spinner itself.

<DemoWithCode code={`<BouncingDots className="opacity-40" size={32} />`}>
  <BouncingDots className="opacity-40" size={32} />
</DemoWithCode>

## Styling

### color

The dots inherit `currentColor`, so the CSS `color` property tints them.

<DemoWithCode code={`<div style={{ color: "#f97316" }}>
  <BouncingDots size={32} />
</div>`}>
  <div style={{ color: "#f97316" }}>
    <BouncingDots size={32} />
  </div>
</DemoWithCode>

### --ld-duration

Sets the bounce speed; the stagger between dots stays proportional at any
speed. Set it on any wrapper — it cascades down to the spinner.

<DemoWithCode code={`<div style={{ "--ld-duration": "1.2s" }}>
  <BouncingDots size={32} />
</div>`}>
  <div style={{ "--ld-duration": "1.2s" }}>
    <BouncingDots size={32} />
  </div>
</DemoWithCode>

### --ld-play-state

Pauses or resumes the animation.

<DemoWithCode code={`<div style={{ "--ld-play-state": "paused" }}>
  <BouncingDots size={32} />
</div>`}>
  <div style={{ "--ld-play-state": "paused" }}>
    <BouncingDots size={32} />
  </div>
</DemoWithCode>

## Usage

Bouncing dots read as "working on it" rather than "loading a page", which
makes them a good fit for chat interfaces and streaming responses. Set the
variables on any wrapper — they cascade down to the spinner.

```tsx title="typing-indicator.tsx"
<div className="text-gray-500">
  <BouncingDots size={16} />
</div>
```
