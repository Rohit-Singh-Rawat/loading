## Color

The loader inherits `currentColor` parent by default. You can tint it in any way you want. It accepts any valid CSS color.

<Demo name="color" />

## Duration

Sets the speed in milliseconds. Higher values are slower, smaller values are faster. Set `--ld-duration` on a wrapper instead — it cascades down to every spinner underneath.

<Demo name="duration" />
