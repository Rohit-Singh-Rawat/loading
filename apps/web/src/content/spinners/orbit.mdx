import { Orbit } from "loading-dev";

## Props

### size

Sets the spinner's dimensions in pixels — the arc, its stroke, and the center
dot scale proportionally. Defaults to 20.

<DemoWithCode code={`<Orbit size={16} />
<Orbit size={24} />
<Orbit size={40} />`}>
  <div className="flex items-center gap-6">
    <Orbit size={16} />
    <Orbit size={24} />
    <Orbit size={40} />
  </div>
</DemoWithCode>

### className

Merged onto the root element, so utilities land on the spinner itself.

<DemoWithCode code={`<Orbit className="opacity-40" size={32} />`}>
  <Orbit className="opacity-40" size={32} />
</DemoWithCode>

## Styling

### color

The arc and the center dot inherit `currentColor`, so the CSS `color`
property tints them.

<DemoWithCode code={`<div style={{ color: "#f97316" }}>
  <Orbit size={32} />
</div>`}>
  <div style={{ color: "#f97316" }}>
    <Orbit size={32} />
  </div>
</DemoWithCode>

### --ld-duration

Sets the rotation speed. Set it on any wrapper — it cascades down to the
spinner.

<DemoWithCode code={`<div style={{ "--ld-duration": "2s" }}>
  <Orbit size={32} />
</div>`}>
  <div style={{ "--ld-duration": "2s" }}>
    <Orbit size={32} />
  </div>
</DemoWithCode>

### --ld-play-state

Pauses or resumes the animation.

<DemoWithCode code={`<div style={{ "--ld-play-state": "paused" }}>
  <Orbit size={32} />
</div>`}>
  <div style={{ "--ld-play-state": "paused" }}>
    <Orbit size={32} />
  </div>
</DemoWithCode>

## Usage

The fixed center dot keeps the spinner anchored while the arc sweeps around
it, which reads well when the spinner replaces an icon in place. Set the
variables on any wrapper — they cascade down to the spinner.

```tsx title="row-action.tsx"
<button disabled={pending} type="button">
  {pending ? <Orbit size={16} /> : <IconRefresh />}
</button>
```
