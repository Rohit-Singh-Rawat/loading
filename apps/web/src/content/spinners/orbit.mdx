## Size

Sets the spinner's dimensions in pixels — the arc, its stroke, and the center
dot scale proportionally. Defaults to 20.

## Custom Classes

Merged onto the root element, so utilities land on the spinner itself.

## Color

Tints the arc and the center dot with any CSS color. Omit them and they
inherit `currentColor` from the surrounding text.

<Demo name="orbit/color" />

## Duration

Sets the rotation speed in milliseconds. Set `--ld-duration` on a wrapper
instead — it cascades down to every spinner underneath.

<Demo name="orbit/duration" />

Pauses or resumes the animation.

## Usage

The fixed center dot keeps the spinner anchored while the arc sweeps around
it, which reads well when the spinner replaces an icon in place. Set the
variables on any wrapper — they cascade down to the spinner.

```tsx title="row-action.tsx"
<button disabled={pending} type="button">
  {pending ? <Orbit size={16} /> : <IconRefresh />}
</button>
```
