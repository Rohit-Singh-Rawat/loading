import { Comet } from "loading-dev";

## Props

### size

Sets the spinner's dimensions in pixels — the ring's thickness and its
leading dot scale proportionally. Defaults to 20.

<DemoWithCode code={`<Comet size={16} />
<Comet size={24} />
<Comet size={40} />`}>
  <div className="flex items-center gap-6">
    <Comet size={16} />
    <Comet size={24} />
    <Comet size={40} />
  </div>
</DemoWithCode>

### className

Merged onto the root element, so utilities land on the spinner itself.

<DemoWithCode code={`<Comet className="opacity-40" size={32} />`}>
  <Comet className="opacity-40" size={32} />
</DemoWithCode>

## Styling

### color

The ring inherits `currentColor`, so the CSS `color` property tints it.

<DemoWithCode code={`<div style={{ color: "#f97316" }}>
  <Comet size={32} />
</div>`}>
  <div style={{ color: "#f97316" }}>
    <Comet size={32} />
  </div>
</DemoWithCode>

### --ld-duration

Sets the rotation speed. Set it on any wrapper — it cascades down to the
spinner.

<DemoWithCode code={`<div style={{ "--ld-duration": "2s" }}>
  <Comet size={32} />
</div>`}>
  <div style={{ "--ld-duration": "2s" }}>
    <Comet size={32} />
  </div>
</DemoWithCode>

### --ld-play-state

Pauses or resumes the animation.

<DemoWithCode code={`<div style={{ "--ld-play-state": "paused" }}>
  <Comet size={32} />
</div>`}>
  <div style={{ "--ld-play-state": "paused" }}>
    <Comet size={32} />
  </div>
</DemoWithCode>

## Usage

The tail fades all the way to transparent, so the spinner reads as fast and
light even at rest. That suits inline affordances on toolbars and headers
where a full-contrast ring would draw too much attention. Set the variables
on any wrapper — they cascade down to the spinner.

```tsx title="toolbar.tsx"
<div className="flex items-center gap-2 text-gray-500">
  <Comet size={16} />
  Saving…
</div>
```
