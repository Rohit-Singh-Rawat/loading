## Props

### size

Sets the spinner's dimensions in pixels. Defaults to 20.

### className

Merged onto the root element, so utilities land on the spinner itself.

## Styling

### color

The bars inherit `currentColor`, so the CSS `color` property tints them.

<Demo name="classic/color" />

### --ld-duration

Sets the rotation speed; the per-bar stagger stays proportional at any speed.
Set it on any wrapper — it cascades down to the spinner.

<Demo name="classic/duration" />

### --ld-play-state

Pauses or resumes the animation.

<Demo name="classic/play-state" />

## Usage

The classic spinner is the most familiar loading affordance there is —
reach for it when you want zero ambiguity about what is happening. It works
best at small sizes next to text or inside controls.

```tsx title="toolbar.tsx"
<span className="text-gray-500">
  <Classic size={14} />
</span>
```
