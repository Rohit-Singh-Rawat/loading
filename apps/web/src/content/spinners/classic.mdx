## Color

Tints the bars with any CSS color. Omit it and they inherit `currentColor`
from the surrounding text.

<Demo name="classic/color" />

## Duration

Sets the rotation speed in milliseconds; the per-bar stagger stays
proportional at any speed. Set `--ld-duration` on a wrapper instead — it
cascades down to every spinner underneath.

<Demo name="classic/duration" />

## Usage

The classic spinner is the most familiar loading affordance there is —
reach for it when you want zero ambiguity about what is happening. It works
best at small sizes next to text or inside controls.

```tsx title="toolbar.tsx"
<span className="text-gray-500">
  <Classic size={14} />
</span>
```
